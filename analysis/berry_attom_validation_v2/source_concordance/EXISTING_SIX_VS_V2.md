# Existing six-county ATTOM vs new v2 jurisdictions

These are **not** the same feature pipeline. The existing six-county runs include Tax Assessor / ACS / location information that is not available for the new Dewey Wayne / Philadelphia / St. Louis County delivery. Do not pool or rank metrics across the two pipelines.

When Tax Assessor becomes available for the v2 counties, add it only as a **separately labeled enrichment sensitivity** unless a new protocol is frozen before use.
